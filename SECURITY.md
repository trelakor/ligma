# Security

Ligma passes Figma sign-ins between your browser and the app (see `src-tauri/src/auth.rs`), so bugs there matter. If you find a vulnerability, report it privately: on GitHub, open [Security > Report a vulnerability](https://github.com/trelakor/ligma/security/advisories/new). Please don't open a public issue for it.

Include what you found, how to reproduce it and the Ligma version (Settings, or the release you installed). Fixes ship in the latest release; older versions aren't patched, and installed apps update themselves.
