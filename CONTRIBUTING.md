# Contributing

Thanks for helping with Ligma.

- **Bugs:** open an [issue](../../issues) with your OS, Ligma version and steps to reproduce. **Report…** in Settings fills most of that in for you.
- **Ideas and questions:** start a [discussion](../../discussions).
- **First contribution?** Look for issues labelled [`good first issue`](../../labels/good%20first%20issue).

## Pull requests

1. Fork the repo and branch from `main` (`feature/<short-slug>` or `fix/<short-slug>`).
2. Build and run it with `npm install && npm run dev`. See [Development](docs/DEVELOPMENT.md) for requirements.
3. Use scoped [Conventional Commits](https://www.conventionalcommits.org), like `fix(tabs): ...` or `feat(plugins): ...`, with no commit body.
4. Keep each PR to one change, and describe what you tested on which OS.

By contributing, you agree your work is released under the [MIT License](LICENSE).
