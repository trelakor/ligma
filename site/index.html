And the smaller things

Low memory use

Tabs you aren't looking at are trimmed, frozen and put to sleep, so hidden files give memory back.

Google sign-in

Works like the desktop app's, with or without the official app installed.

Local fonts

Uses Figma's font helper, and starts it when it isn't running.

Automatic updates

Downloaded in the background and installed in place, so you stay signed in.

Interface scale

Zoom Figma, the tabs and menus together, from 50% to 200%.

Image adjustments

Copy an image's exposure, contrast and the rest, and paste them onto another without the image.

Toolbar modes

Choose which of Draw, Design, Motion and Dev Mode the toolbar's switch offers.

Classic home

Keeps Figma's long-standing home page on accounts trying the new one.

Free AI image tools, on your computer

Figma asks for a paid plan in free projects. Ligma puts its own in the same spots in the image bar, running on your computer, so your images never leave it.

  1. Select objectClick, brush or lasso an object, then isolate it on its own layer or erase itSAM 2.1, on Windows and Apple silicon
  2. Remove backgroundCuts out the subject and keeps the original hidden underneathApple's Vision on macOS 14 and later, BiRefNet on Windows
  3. VectorizeTraces it into flat-colored shapes, then recolor or cut down the colorsLigma's own tracer, nothing to download

Ligma asks before downloading a model the first time one is needed.

Install

Builds aren't signed yet, so your system asks once before the first launch. After that, Ligma updates itself.

macOS Apple silicon and Intel

  1. Download the .dmg and drag Ligma to Applications.
  2. The app isn't notarized yet, so run this once in Terminal:
    xattr -dr com.apple.quarantine /Applications/Ligma.app
  3. Or open it anyway from System Settings → Privacy & Security.

Windows

  1. Download and run the -setup.exe installer.
  2. If SmartScreen warns, choose More info → Run anyway.
