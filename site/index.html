Figma, without the weight

A lightweight desktop app for Figma on macOS and Windows. About 4 MB, with tabs, themes, your plugins in the left rail and your file on Discord.

What you get

Ligma opens figma.com in your system's webview (WebView2 or WKWebView) instead of shipping its own browser, and adds what the web version is missing.

Tabs

Like the Figma desktop app: pinning, previews on hover, emoji icons, shortcuts and your tabs reopened from last time.

Low memory use

Tabs you aren't looking at are trimmed, frozen and put to sleep, so hidden files give memory back.

Themes

Light and dark variants that recolor Figma's interface, never your designs, plus an adjustable interface scale.

Plugins in the left rail

Your saved and development plugins sit under Figma's own buttons, one click to run.

Development plugins

Import a plugin from its manifest.json, which figma.com doesn't support.

Discord Rich Presence

Shows your file, page and tool, with per-file hiding and optional invites to files.

Google sign-in

Works like the desktop app's, with or without the official app installed.

Local fonts

Uses Figma's font helper, starting it when needed.

Automatic updates

Downloaded in the background and installed in place, so you stay signed in.

Make Figma your own

Pick one theme for light mode and one for dark. Each one tints Figma's greys and gives every editor's brand color its own.

Ligma or the official app?

Both are Figma. Ligma is a lighter shell with a few extras.

Install

Builds aren't signed yet, so your system asks once before the first launch. After that, Ligma updates itself.

macOS

Download the .dmg and drag Ligma to Applications. The app isn't notarized, so run this once:

xattr -dr com.apple.quarantine /Applications/Ligma.app

Or allow it in System Settings → Privacy & Security → Open Anyway.

Windows

Download and run the -setup.exe installer.

If SmartScreen warns, choose More info → Run anyway.
