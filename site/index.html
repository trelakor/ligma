Figma, without the weight.

A desktop app for Figma on macOS and Windows that uses your system's own webview instead of shipping a browser. Tabs, themes, your plugins in the left rail and your file on Discord.

Everything the browser tab is missing

Ligma opens figma.com in WebView2 or WKWebView and adds what the web version doesn't have, so it feels like the desktop app at a fraction of the size.

Tabs, like the desktop app

Every file gets its own tab, with Home pinned on the left. Point at a tab to see how it last looked, and pick up where you left off next time.

  • Pin a tab from its right-click menu, and it shows just its icon.
  • Emoji at the start of a file's name becomes its tab icon.
  • Shortcuts as usual: Ctrl+T, Ctrl+W and Ctrl+Tab (Cmd on macOS).
  • Asleep tabs give their memory back and reload when you open them.

Your plugins, one click away

Every plugin and widget saved to your Figma account sits in the editor's left rail, under Figma's own buttons, with its icon. Click one to run it.

  • Commands show as a menu when a plugin has more than one.
  • Widgets go straight onto the canvas.
  • Reorder by holding Ctrl and dragging. The order is kept for every file.

Your file on Discord

Your profile shows the file you're in, the page or slide, and the tool in your hand. Keep any file private from its tab's right-click menu.

  • Hide files by default and show only the ones you choose.
  • Invites (optional) let friends ask to join, and the file opens in their Ligma.
  • Every product: Design, FigJam, Slides, Make, Buzz and Sites.

Low memory use

Tabs you aren't looking at are trimmed, frozen and put to sleep, so hidden files give memory back.

Google sign-in

Works like the desktop app's, with or without the official app installed.

Development plugins

Import a plugin from its manifest.json, which figma.com doesn't support.

Local fonts

Uses Figma's font helper, and starts it when it isn't running.

Automatic updates

Downloaded in the background and installed in place, so you stay signed in.

Interface scale

Zoom Figma, the tabs and menus together, from 50% to 200%.

Nine themes. Try them on this page.

Each theme has a light and a dark version. Ligma tints Figma's greys and gives its brand color to buttons, selection and menus. Click a swatch to see it here.

Install

Builds aren't signed yet, so your system asks once before the first launch. After that, Ligma updates itself.

macOS Apple silicon and Intel

  1. Download the .dmg and drag Ligma to Applications.
  2. The app isn't notarized yet, so run this once in Terminal:
    xattr -dr com.apple.quarantine /Applications/Ligma.app
  3. Or open it anyway from System Settings → Privacy & Security.

Windows

  1. Download and run the -setup.exe installer.
  2. If SmartScreen warns, choose More info → Run anyway.
